# 远程 MCP 使用指南

连接微墨·豆瓣的远程 MCP 后，你可以让 AI 助手查询已同步的书影音记录，查找作品、阅读短评、统计评分，或整理年度回顾。**无需安装桌面 App**，数据来自微墨·豆瓣服务器上的备份。

## 可以怎样使用

- 「列出我今年看过并打了五星的电影，附上当时的短评。」
- 「找出我读过的村上春树作品，按标记日期排序。」
- 「我看过的电影里，哪些导演出现得最多？」
- 「根据我的评分和短评，整理一份年度书影音回顾；说明统计范围和最近同步时间。」

MCP 只查询已有记录，不修改评分或短评，也不替你操作豆瓣账号。需要更新记录时，请先到[微墨·豆瓣网页版](https://weimo.ink/douban/)同步，再让助手重新查询。

## 接入前准备

1. **确认助手支持远程 MCP**：需要支持 Streamable HTTP，以及自定义 `Authorization` 请求头。部分客户端将传输方式简称为「HTTP」。
2. **向管理员获取 MCP 访问凭证**，并确认希望查询的豆瓣账号已开放访问。当前为邀请制；在网页版同步数据，不会自动获得 MCP 权限。
3. **确认服务器已有数据**：查询自己的记录时，先在网页版完成同步。本机 App 的备份与网页版分别保存，仅在桌面 App 同步过的数据不会自动出现在远程 MCP 中。

当前使用访问凭证连接，没有个人登录或 OAuth 授权入口。仅支持 OAuth 登录、无法设置请求头的客户端暂不适用。

## 添加连接

打开 AI 助手的 MCP 设置，添加一个远程服务，填写：

| 设置项 | 填写内容 |
|---|---|
| 名称 | `weimo-douban-remote`，也可以自行命名 |
| 传输方式 | Streamable HTTP／HTTP |
| 服务地址 | `https://weimo.ink/douban/mcp` |
| 请求头名称 | `Authorization` |
| 请求头值 | `Bearer <管理员提供的 MCP 凭证>` |

将占位文字及尖括号替换为实际凭证，保留 `Bearer` 后面的一个空格。凭证只填写在客户端连接设置里，不要发给聊天中的助手，也不要附在网址后面。

如果客户端通过 JSON 配置 MCP，并支持 `mcpServers` 格式，可以参考以下示例：

```json
{
  "mcpServers": {
    "weimo-douban-remote": {
      "type": "http",
      "url": "https://weimo.ink/douban/mcp",
      "headers": {
        "Authorization": "Bearer <MCP 凭证>"
      }
    }
  }
}
```

不同客户端的配置结构和字段名称可能不同，请按对应客户端的要求填写同样的地址与请求头；将新条目合并到已有配置中。保存后启用或重新连接服务，确认助手能发现下方五个工具。

服务地址是供 MCP 客户端调用的接口。直接用浏览器打开时出现 `401`，不代表服务离线。

## 第一次查询

连接成功后，可以直接把这段话交给助手：

> 请使用 weimo-douban-remote，先列出我可以查询的账号。如果有多个账号，让我选择；只有一个时使用该账号。然后统计它已同步的电影、图书和音乐标记数量，并说明最近同步时间。如果数据还在同步，请注明结果可能不完整。

助手应先调用 `list_users`，从结果中取得豆瓣用户 ID（`uid`），再使用这个 ID 查询。**可查询账号以 `list_users` 的实际结果为准**；不能通过手动填写其他 ID 获得访问权限。

| 工具 | 用途 |
|---|---|
| `list_users` | 查看可查询账号、标记数和最近同步时间，作为查询的第一步 |
| `search_marks` | 查找具体作品的标记、个人评分和短评，支持筛选及分页 |
| `get_subject` | 查看某部作品的已缓存详情，例如豆瓣评分、导演或作者；作品编号从搜索结果取得 |
| `get_stats` | 统计符合条件的全部标记，包括类别、状态、个人星级和标记年份 |
| `list_facets` | 统计导演、类型、国家／地区、作者等维度，也可取得后续精确筛选所需的名称 |

如果同时连接了本地和远程 MCP，在提问时明确指定 `weimo-douban-remote`，避免混用两个来源的数据。

## 筛选与查询示例

日常使用时，用自然语言说明需求即可，助手负责填写工具参数。需要检查调用详情或排查错误时，可参考下面的参数对象。

先用 `search_marks` 做最小查询，将 `uid` 的占位文字换成 `list_users` 返回的实际 ID：

```json
{
  "uid": "从 list_users 获取的实际 ID"
}
```

确认成功后，再查询「2026 年标记为看过、个人评分五星的电影」：

```json
{
  "uid": "从 list_users 获取的实际 ID",
  "category": "movie",
  "status": "collect",
  "my_rating_min": 5,
  "my_rating_max": 5,
  "marked_from": "2026-01-01",
  "marked_to": "2026-12-31",
  "limit": 20
}
```

这些字段直接放在参数对象顶层，不要额外包进 `filter` 或 `page`，也不要把整个对象变成字符串。`search_marks`、`get_stats`、`list_facets` 每次调用都需要 `uid`，即使只有一个可查询账号。

| 想筛选什么 | 使用方式 |
|---|---|
| 电影、图书、音乐 | `category` 分别为 `movie`、`book`、`music` |
| 看过／读过／听过，正在进行，想看／想读／想听 | `status` 分别为 `collect`、`do`、`wish`；结果取决于服务器实际已同步的内容 |
| 我给出的星级 | `my_rating_min`／`my_rating_max`，范围为 1–5 星；未评分记录不匹配星级范围 |
| 某段时间标记的作品 | `marked_from`／`marked_to`，格式为 `YYYY-MM-DD`，包含起止日期 |
| 某年上映、出版或发行的作品 | `release_year_min`／`release_year_max`；与标记日期不同 |
| 标题、别名或短评中的文字 | `query`，按字面子串搜索，最多 200 字符 |
| 指定导演、类型、地区或作者 | 先用 `list_facets` 获取精确值，再通过 `facets` 筛选，例如 `[{"name":"directors","value":"王家卫"}]` |

`facets` 支持 `genres`、`countries`、`directors`、`press`、`authors`、`translators`、`singers`，多个条件需同时满足。它们是作品信息维度，不是用户自定义标签。

需要完整计数时，让助手用 `get_stats` 传入相同的筛选条件；`get_stats` 不需要 `limit` 或 `offset`。例如「今年看过」应使用今年的**标记日期**范围，不能替换为作品上映年份。

## 正确理解结果

- **总数与当前页不同**：`total` 是匹配总数，`items` 是当前页内容。搜索默认返回 20 条，每页最多 100 条；继续读取时使用返回的 `next_offset`。不要将第一页当作完整清单。
- **个人星级与豆瓣评分不同**：个人评分为 1–5 星，豆瓣公共评分是另一项作品信息。查询「我打五星」应筛选个人星级。
- **数据新鲜度取决于同步**：查看 `last_synced_at` 或 `sync`。同步进行中的结果可能尚不完整；翻页期间如果有新数据同步，各页内容也可能变化。
- **缺失详情不会自动补抓**：未同步的作品详情、评分或短评可能为空。MCP 查询不会启动同步，可先回网页版更新数据后重试。
- **远程结果来自服务器**：`data_source=server_cache` 表示服务器缓存。关闭电脑上的 App 不影响远程查询，但需要网络连接。

整理年度回顾或榜单时，可以要求助手注明账号、日期范围、筛选条件、匹配总数和同步时间，并区分记录事实与助手的推测。

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 连接返回 `401` | 检查是否配置了 `Authorization` 请求头、`Bearer ` 前缀和有效 MCP 凭证；凭证更换后需更新设置并重新连接 |
| 连接返回 `403` | 请求来源可能不受支持；确认使用正确地址和支持请求头的 MCP 客户端，仍失败时联系管理员 |
| 返回网页内容、`404` 或无法识别工具 | 检查地址是否完整填写为 `https://weimo.ink/douban/mcp`，传输方式是否为 Streamable HTTP |
| 提示账号或作品不在开放范围 | 先调用 `list_users` 确认可用账号；作品编号从该账号的搜索结果获取，新增账号权限请联系管理员 |
| 账号列表为空，或查不到刚同步的数据 | 确认同步发生在网页版、账号已开放且同步已完成；本地 App 的数据不会自动上传到远程 MCP |
| 返回 `429`、`503` 或提示查询繁忙 | 稍后重试，并减少并行调用；服务有共享请求额度，不适合连续批量导出 |
| 提示结果过大或查询超时 | 减小 `limit`，或按类别、日期、关键词缩小范围；需要计数时优先使用 `get_stats` |
| 返回 `502`／`504`，或连接中断 | 稍后重试；持续失败时，将发生时间、工具名称和原始错误提供给管理员 |
| 提示缺少 `uid`，调用详情却显示 `{}` | 查看实际参数及客户端解析错误；按「只传 uid → 加一个条件 → 逐项增加」重试，必要时换模型或客户端做对照 |

在一次 ZCode + GLM-5.3 会话中，曾出现单参数成功、多参数解析失败后被客户端替换为 `{}` 的情况。切换到远程 MCP 不会自动解决这类问题；不能因此删除原本需要的筛选条件，再把未筛选结果当作答案。完整排查方法见 [AI 查询问题排查](troubleshooting.md)。

服务端已通过协议与公网工具调用验证；具体客户端、版本和模型组合仍需实际连接验证。反馈时注明使用的是远程连接，隐去访问凭证和私人短评。

## 数据与访问权限

持有同一访问凭证的人，可以查询相同的开放账号，包括这些账号已同步的短评；当前不是按每位使用者的个人登录划分权限。请仅在可信客户端的连接设置中保存凭证，不要放入公开仓库或分享完整配置。

查询结果会进入所选 AI 助手的上下文，是否发送给云端模型取决于助手设置。微墨·豆瓣远程 MCP 只提供读取和查询，不提供修改、删除、触发同步或直接导出 CSV 的工具。

需要安装、扩展账号范围或维护服务，请参阅[远程 MCP 运维说明](../ops/mcp/README.md)。本地 App 用户也可以选择[本地 MCP 使用指南](local-guide.md)。
